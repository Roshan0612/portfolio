# Roshan Gawade Portfolio

Personal portfolio website for Roshan Gawade, a computer engineer and full-stack developer.

## Tech Stack

React, TypeScript, Vite, Tailwind CSS, Framer Motion, GSAP, Three.js, and Lucide React.

## Run Locally

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - Start the development server
- `npm run build` - Create a production build
- `npm run lint` - Run ESLint
- `npm run preview` - Preview the production build

The site includes responsive sections for projects, skills, experience, education, contact, and resume download. Resume files are stored in `public/`.
